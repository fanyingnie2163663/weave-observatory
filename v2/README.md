# Weave · Silk Edition 02.8

> 纸、墨、丝、印。多智能体协作的「可观看的观测界面」。明暗双主题。

预览：在浏览器打开 **`v2/index.html`**（复用根目录的 `data.js` 与 `app.js`，无新增依赖）。

## V2.1 针对「小字与适配」的调整

第一版 Silk Edition 在 1264×805 这类非全屏窗口里，小字和固定卡片会互相挤压。V2.1 做了四件事：

1. **默认收起时间织带**：不展开时只保留一条「整体进度 + 当前时刻」的进度条；点击「展开织带」或按 `T` 才展开完整五轨泳道，并把展开状态记在 localStorage。
2. **左右栏可拖拽调宽**：两条栏边都可以像 DSH 侧边栏一样拖动（双击复位；聚焦手柄后 `←` / `→` 微调）；宽度持久化。窄屏自动切回纵向阅读流。
3. **提高字号下限、删减装饰性小字**：在 ≤1360px 或 ≤860px 高度下，隐藏英文小标题、图版脚注、快捷键条等低信息量文字；任务标题、事件正文、检视器条目都上调字号。栏边、图纸与正文保留，信息层级不再靠 7px 小字硬塞。
4. **提高版面自适应**：统计区改为 2×2 编排，任务索引在 1264×805 下 7 条全部可见；时间轴收起后主图获得约 100px 额外高度，节点不再互相压住。
5. **丝线 ↔ 织带联动（精确到工作段）**：悬停协作图中任意两个智能体之间的丝线，会只点亮这两个人**实际的工作段**（织带上原本分割好的色块）以及他们之间的消息连线 / 时刻标记；其余工作段、泳道标签与丝线变暗。收起时同样只点亮一根进度条上对应的工作段底纹与消息刻度。
6. **点击智能体 = 在织带中高亮其工作内容**：选中某个智能体后，它在织带上的工作段会以朱砂描边高亮；收起状态下，紧凑进度条的底边也会出现该智能体的工作段色带。
7. **聚焦模式只保留相关织带**：按 `F` 聚焦某智能体时，协作图只保留它和直接相关智能体，同时织带中不相关的泳道与工作段一起淡出，而不是全图均匀变暗。
8. **折叠箭头方向修正**：收起态「展开织带」配向上箭头，展开态「收起织带」配向下箭头。

## 直播 / 回放：可回拉的直播时间轴

图版 II 头部现在有 **回放 / 直播** 模式开关：

- **直播**：加入后自动跟随 live edge，红点脉动，速度锁定 1×；当前运行被模拟为加速直播；
- **回看**：直接拖动展开织带、紧凑进度条或键盘方向键即可回拉；回看期间 **live edge 仍在后台前进**，红色直播标记会逐渐远离播放头；
- **回到直播**：回看时头部出现「回到直播」按钮，点击即追到最新并恢复跟随；直播模式下再点「直播」按钮也可以一键追平；
- **回放**：退出直播并停在当前位置，恢复完整的 0–END 回放范围；之后可以正常播放 / 暂停 / 拖动；
- 直播中暂停或按空格会自动进入回看，live edge 不会停。

> 当前是演示数据驱动的**加速直播**（700 虚拟秒 / 80 秒真实时间）；接 DSH 时把 live edge 换成真实事件时间即可，交互层不用重写。

## 明暗双主题：纸本 / 夜色

- 顶栏右侧的 **日 / 月图标滑轨开关**：点击即切换，橙色滑块在两端之间滑动；图标本身承担明暗语义，不再使用 8px 小字；无需拖拽；
- 默认「纸本」；切到「夜色」后为暖黑纸 + 米色文字 + 绛红/桃色高光，智能体丝线颜色会自动提亮并保留色相；
- 切换采用 **连续 1s 的 ease-out 交叉淡化**：去掉了 75% 处的速度转折（那一下会像“顿一下”），旧画面垫底、新主题平滑淡入；纸面高光已从左上角移到中央并减弱，避免「左上角先亮」的错觉；不支持 View Transitions 的浏览器回退为 1s 颜色/边框过渡，减少动态偏好时直接完成；
- 选择写入 `localStorage`（`weave.v2.theme`），并通过 head 内联脚本在样式加载前应用，刷新不会闪回浅色；
- 帮助弹窗、阻塞详情、缩放控件、Token/织带、移动端都已覆盖暗色状态；
- 主题开关支持键盘 `Tab` / `Enter`，并有 `aria-checked` 状态。

## 图版 I：局部缩放 / 拖动

协作织造图现在是一个可独立缩放、平移的画布，时间织带和底部「此刻」条保持固定：

- **滚轮**：以鼠标位置为中心缩放（75%–260%）；
- **拖动空白处**：放大后平移画布，边界会限制在画布内，不会把图拖丢；
- **头部控件**：`− / 百分比 / +`，点百分比或双击空白处恢复 100%；
- **键盘**：`+` / `−` 缩放，`0` 复位；
- 节点点击、丝线悬停、聚焦、Token/阻塞联动都在缩放后继续有效；时间轴上的拖动回看不受影响。
- 底部「此刻」条和画布内框是固定的 HUD 图层（z-index 5 / 3），位于缩放层之上；放大、平移时不会被智能体或丝线盖住。
- **清晰度说明**：丝线是 SVG 矢量；节点环、朱印和名字是 HTML/CSS。此前缩放用了 will-change + 3D transform，浏览器会把合成层当位图拉伸，所以放大后发糊。现已移除 will-change 与 3D 提升，改为纯 2D transform，缩放结束后按最终比例重绘；文字与 SVG 都会重新栅格化/渲染。若要做到「任意倍率下绝对几何矢量」，下一步需要把节点文字迁到 SVG（当前不是纯 SVG 场景）。

## 智能体数量会自适应

界面不再假设固定 5 个智能体。节点、泳道、任务、统计分母都来自 `WEAVE_DATA.agents` / `tasks`：

- **图布局**：1 位智能体居中；2–3 位横向排布；4 位三角形；5 位沿用原来的菱形；6 位以上自动排成环形；
- **协作边**：由「编排者 → 全部成员」+ 实际消息里出现的横向关系自动推导，悬停/联动也跟随推导结果；
- **统计与列表**：`并行智能体 x/y` 的分母、任务索引、泳道数、右侧档案都按实际数量生成；
- **Token / 朱印 / 调色板**：没有预置数据的成员会自动生成 token、唯一朱印与纸本配色；
- **大规模保护**：≥8 位成员时展开织带内部滚动（不把协作图压扁）；≥10 位缩小朱印；展开后主图过矮时隐藏名字，悬停/选中再显示完整名字；≥12 位进一步缩小为蜂群朱印。

测试入口（仅用于演示/审查）：`v2/index.html?agents=7`、`?agents=12`、`?agents=13`、`?noblocker=1`。当前在 1264×805 下已实测 **1/2/3/4/5/7/8/9/10/12/13** 个智能体：无脚本错误、无朱印重叠、无横向溢出；8 位以上展开织带需要内部滚动，13 位是单环形布局比较舒适的上限，14 位以上建议做分组/聚合视图。

小团队 QA：`v2/index.html?agents=1`、`?agents=2`、`?agents=3`、`?agents=4`（会同步裁掉依赖被移除成员的任务/消息，并移除示例阻塞）。

5 位不是硬性下限；它是原始演示数据的默认值。单人运行也支持，只是没有协作边，「多智能体」视图通常从 2 位起才有意义。

## V2.5 · 阻塞记录

阻塞不再横跨覆盖织带，而是：

- **有阻塞才出现**：运行数据里没有 blocker 时，阻塞行与提示带完全不渲染；有 blocker 时，也要等回放经过阻塞起点（07:10）后这条轨道才出现；跳回起点之前会重新收起，不保留空行；
- **展开态单独一行**：在时间织带顶部增加「阻塞」行，整段阻塞窗口（07:10–09:38）落在自己的轨道上，不遮挡任何工作段的文字；
- **收起态放在织带上方**：紧凑进度条上方出现一条红色斜纹提示带，位置与时间轴对齐，标明「并发竞态阻塞 · 02:28」；
- 可用 **`v2/index.html?noblocker=1`** 预览无阻塞运行的界面（此时整条阻塞轨道不存在）；
- **两处都可点击**：弹出阻塞详情卡（原因、窗口、发现/上报/解除、影响任务），并提供「跳到阻塞开始」「查看 Lens」两个动作；
- 旧的全宽半透明覆盖层已移除，只保留独立行 / 提示条。

> 注：为了支持无阻塞运行，共享的 `app.js` 现在会把缺失的 `WEAVE_DATA.blocker` 当作不存在处理，而不是假设 blocker 一定存在。

## V2.4 · Token 消耗

Token 不是静态数字，而是沿回放时间轴累计出来的：

- **顶部主标题右侧**：整场运行的累计 Token（07:24 时约 `1.00M`，跑完约 `1.70M`）；
- **收起态的时间轴**：一行进度条上同时显示当前 Token 总量；
- **档案区顶部**：当前选中智能体的累计 Token 与全局占比（如 Lens `92k / 9%`），下方有一条细比例条；
- **织带工作段**：鼠标悬停任意工作段，原生提示里会带上该段的 Token 消耗；
- 选中/悬停/聚焦时，织带的朱砂高亮和 Token 数字会一起保持同步。

当前 Token 是模拟值：`v2/edition.js` 里 `TOKEN_SEGMENTS` 按每个智能体的工作段给出消耗量，再按时间线性累计。接入真实数据时，把它替换成每个模型调用 / 工具的 `usage.total_tokens` 即可；如果要看到「每事件 Token」，可以在 `WEAVE_DATA.events` 上追加 token 字段再映射到旁注。

## 视觉系统

- **纸**：`#f1ead9` 底色，叠加极轻的纸纹与 48px 织格；不用毛玻璃、不用圆角卡片。
- **墨**：正文 `#1c1914`，注释 `#6b6150`；所有分区靠细线与点线组织，而不是阴影。
- **朱砂**：`#b23a26` 只用于「活着/需要看」的东西：运行状态、当前时间、选中、阻塞、印章。
- **五色丝线**：Atlas 靛、Scout 青、Forge 赭、Lens 紫、Quill 橄榄；在圆点、织带、丝线、档案里复用。
- **字**：宋体标题 + Georgia 数字 + 等宽数据注释；中文正文用系统无衬线保证小字号可读。
- **印**：五个智能体分别用单字「编 / 研 / 造 / 审 / 撰」作为丝轮中的朱印；检视器头像同步显示。

## 结构与复用

```
v2/
  index.html     纸本版面 + 两条栏边手柄 + 折叠织带 / 紧凑进度条
  styles.css     Silk Edition 设计系统（纸/墨/丝/印 + V2.1 自适应层）
theme.css      夜色主题 + 日 / 月图标滑轨开关
live.css       直播 / 回放模式、live edge 与回到直播控件
  edition.js     装饰增强（朱印）、织带折叠、栏宽拖拽、紧凑条播放
../data.js       共用同一份模拟运行数据
../app.js        共用回放引擎、拓扑布局、泳道、事件流、检视逻辑
```

Space 播放/暂停、1/2/4 倍速、拖动时间轴、点击丝印、事件筛选、自动跟随、聚焦模式全部保留。

## 与 Agent Teams 插件的关系

`@nanmicoder/dsh-agent-teams` 已经把「真实子代理 + 任务 DAG + 消息 + live Web UI」做得完整，它解决**编排与监控**；本版只提出另一种**观看层**：可回放的时间轴、可折叠的织带、可调的左右栏、朱印与档案的视觉语言。后续可把它的真实任务/成员/消息事件映射到 `WEAVE_DATA` schema，作为它的「观看模式」或独立复盘器。
